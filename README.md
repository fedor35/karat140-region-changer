# KARAT frequency plan / КАРАТ-140 LW — настройка по оптической головке

<p align="center"><img src="docs/images/karat-140-lw.png" width="420" alt="Счётчик воды КАРАТ-140-Э2-15-LW: ЖК-индикатор, DataMatrix с номером, окно оптической головки"></p>

Счётчик воды КАРАТ‑140‑Э2 LW: на лицевой панели — DataMatrix с номером прибора (его сканирует
приложение) и окно оптической головки, к которому прикладывается адаптер. Фото —
[НПО «Карат»](https://www.karat-npo.com/catalog/smart_pribory/schetchik_vody_karat_140_e2_s_lw_nb/).

Приложение для настройки приборов КАРАТ по оптике (адаптер FTDI FT232R + оптическая головка):

- **Частотный план** модема Sense4Dev: Россия RU868 (план 140) / Казахстан KZ868 (план 1001).
- **Резервный канал КАРАТ‑140 LW**: параметры связи, альтернативный LoRa‑канал, спящий режим.
- **Ключи LoRaWAN** читаются из прибора (DevEUI, JoinEUI, AppKey) — наклейка с ключами не нужна.
- Номер прибора и модель — со скана DataMatrix / GS1‑128 (K‑140, Карат‑140 LW, КАРАТ‑927 LW).
- Каждая операция отправляется на сервер учёта, который сверяет ключ с сетевым сервером
  и заводит новый прибор автоматически.

## Скачать

В разделе **Releases** справа:

| Файл | Что это |
|---|---|
| `*-android.apk` | Android 8.0+, телефон с USB OTG; при установке разрешите «неизвестные источники» |
| `*-windows-x64.exe` | Windows 10/11, консольное приложение с текстовым интерфейсом (`karat-freq.exe`) |
| `*-linux-x64` | Linux x86‑64, то же |
| `SHA256SUMS` | контрольные суммы |

Desktop: запустите файл без параметров — откроется TUI (F1 — частотный план, F2 — резервный
канал 140 LW). Справка по командам: `karat-freq --help`, например `karat-freq lw read -p COM5`.

Android: подключите FTDI FT232R через OTG, выберите вкладку, отсканируйте код прибора,
приложите головку к прибору и нажмите «Прочитать» / «Применить план».
